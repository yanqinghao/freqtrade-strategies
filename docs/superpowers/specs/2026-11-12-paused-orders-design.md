# 在订单面板管理暂停入场计划

用户要求暂停计划也在order中可见，点详情取消。沿用原生订单面板、身份/topic/消息绑定、6条分页和二次确认，不增加状态通知。

列表将尚未完成的初始入场计划纳入全部/挂单，并加暂停筛选；关联真实交易时只显示一行并标注暂停状态。纯计划不计算持仓数量或浮盈亏，不伪装成交易所挂单。详情展示原价格、SL/TP、软止损规则、原因和有效期；回执未知/正在撤单明确说明不能当作未下单。

取消采用既有EntryPause.cancel，持久禁止后续恢复；不调用全平或新增订单。纯暂停确认取消后从活动列表移除。若有撤单/未知回执仍需核对，不能声称交易所已撤单。确认与执行都重读稳定版本：阶段/原参数/尝试身份/实际本地订单与成交改变则拒绝旧按钮；频繁行情诊断更新不使取消确认失效。若计划已恢复/已成交，要求刷新现有订单操作，不对旧计划按钮自动撤新单。

复用order_management.py承载交易线程只读查询与持久取消，order_panel.py承载列表和详情；不新增依赖或数据库schema，不改交易恢复条件或通知样式。
